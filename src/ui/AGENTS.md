# src/ui/ — menu look and HUD

The "bold arcade" kit every menu is built from, and the MENU STYLES that re-dress it.
The root `AGENTS.md` (rules, stack, map) applies too. Keep this file up to date when you change what it describes.

## Menu look ("bold arcade")
Files: `src/ui/arcade.js` (the kit), `src/ui/listScreen.js`, `src/ui/button.js`

Every menu is built from one kit so the game reads as one thing: `ArcadeBg` (moving backdrop in the screen's colour - call `.update(t)` every frame), `titleBanner` (slanted title plate top-left, slides in, breadcrumb beside it), `panel` / `tab` (slanted panels, hard shadows, colour along the bottom), `rowBar` (the picked row: slanted colour bar + chevron, grows in), `hintBar` (the bottom strip: turns the old plain hint string into key chips - entries split on 3+ spaces, leading key-like words become chips), `slant` (the basic parallelogram), `pixIcon` (chunky icons: files, flask, shop, trophy, dummy, pad, bulb, star, back, speaker, crt, touch, screen). Section colours in `ARC.sections` (fight red, options blue, other green, trinkets purple, shop gold, files pink, test lime, achievements gold, stage orange, title cyan). `ListScreen` = the list-left / details-right layout (TRINKETS, OTHER: big icon per entry). `resultsCard.js` = THE RESULTS, the whole of BossReward's win screen (the tally, the GRADE stamp, the rewards; see src/scenes/AGENTS.md BOSS FIGHTS). `deathCard.js` = the boss DEATH CARD, the whole of BossReward's defeat screen (painted portrait, quote, tip, costume line, progress line) (see src/scenes/AGENTS.md BOSS FIGHTS). `hud.js` calls fighters' own plate extras: THE DEVOTED's OBLATION meter (`drawDevotionHud`) and GNASH's PSYCHO meter beside his damage % (`drawPsychoHud`). `makeButton` draws a slanted plate behind the Text (`t.plate`, follows it every frame; MatchScene.addUI registers the plate too). Layering: static panels at depth -10, cursors -5, text 0, backdrop -20.

## MENU STYLES
OPTIONS > MENU STYLE (saved with the other options as `settings.menuStyle`, `rebirth.options`) picks one of `MENU_STYLES` in arcade.js: BOLD ARCADE (the original), RETRO REWIND, BUBBLE BLAST, GRAFFITI, SLICK! and CORRUPTED CODE. `setMenuStyle(id)` recolours `ARC` in place (`pal`: ink / deep / panel / panel2 / line / edge / dim - so read ARC's colours when you draw, not at module load) and the kit follows the style everywhere it draws:
- `slant` is the style's basic shape (`shape`): `slant` = the parallelogram (BOLD ARCADE, RETRO REWIND), `sleek` = a longer lean (SLICK!), `round` = a rounded pill (BUBBLE BLAST), `spray` = corners nudged by a fixed `hash` of the position so it looks hand-sprayed but never jitters (GRAFFITI), `glitch` = a block with one slice pushed sideways (CORRUPTED CODE). `plainSlant` is always the parallelogram: the match HUD (hud.js) and MatchScene's banners use it, so a match looks the same in every style.
- `ArcadeBg.update` draws the style's backdrop: `arcade` (slabs + speed stripes), `retro` (dusk sky, striped synthwave sun, mountains, a neon grid rolling in, scanlines, a VHS tracking band and a REW / PLAY counter `osd` in the corner), `bubble` (deep blue sea, polka dots, glossy bubbles rising), `graffiti` (brick wall, old sprayed tags and drips, a street light, a line being sprayed), `slick` (near-black, a soft band sweeping, a dot grid, thin gliding lines), `corrupt` (green code rain, scanlines, red / cyan tears with a burst every couple of seconds).
- `panel`, `titleBanner` (title colours `titleColor` / `titleStroke` / `titleShadow`; BUBBLE's title wobbles, CORRUPTED's has red / cyan ghosts that twitch), `hintBar`'s key chips and `makeButton` (through `slant`) are dressed per style too: chrome stripes + a faint grid (RETRO), gloss + shine dots (BUBBLE), paint drips + tape (GRAFFITI), a thin frame and a left accent bar (SLICK!), offset red / cyan outlines (CORRUPTED).
- Screens that draw their own art (the main menu tiles, the shop's shelves) keep it; they pick up the style through `slant`, `panel` and the backdrop. OPTIONS restarts itself after a change so you see it at once (`cycleStyle`).
- A new style = an entry in `MENU_STYLES` + its branch in `ArcadeBg.update` (and `panel` / `titleBanner` if it needs its own dressing).
