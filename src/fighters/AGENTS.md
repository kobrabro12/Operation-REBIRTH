# src/fighters/ — fighters

Every fighter, its sheets and mechanics, and how the Fighter class is split up.
The root `AGENTS.md` (rules, stack, map) applies too. Keep this file up to date when you change what it describes.

## Fighter topics
Files: `fighterSpecials.js` (K moves), `fighterDefense.js` (shield/dodge/hitstun), `fighterGrab.js`, `fighterLedge.js`, `fighterLimit.js` (start + beam), `limitUndertow.js` (Mr Wake), `limitBlade.js` (Lacy), `limitMosh.js` (NU: WALL OF SOUND limit + Crowd Surf), `fighterBeat.js` (NU: ON BEAT passive, STREAK, Power Chord hold), `limitAero.js` (AERO: Screensaver + Full Aero), `fighterWhatOnceWas.js` (WHAT ONCE WAS: SIGNAL meter + 3 MODES and their grabs, Channel Surf, Wrong Door, OUT OF BODY + the TV head, screen beams, LEVEL 0 + the Bacteria), `fighterTaunt.js` (taunts, 1 key), `fighterRender.js` (sprites/anim), `fighterCostumeFx.js` (auras, dragon, trails), `fighterSpeech.js` (costume quips)

Each is a class whose methods get attached to `Fighter.prototype`. A method name may only exist once across them (it throws on load if not).
